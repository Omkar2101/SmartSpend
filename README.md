# SmartSpend - AI Expense Management Platform\n\n## 🎯 Project Overview\n\nSmartSpend is a full-stack AI-powered expense management platform that helps users track expenses, connect Gmail for automated receipt processing, and gain insights into spending patterns.\n\n**Technology Stack**:\n- **Backend**: Node.js/Express, TypeScript, PostgreSQL, Prisma, Clerk Auth\n- **Frontend**: React 19, TypeScript, React Router, React Query, Vite, Clerk React\n- **Infrastructure**: Docker Compose for local development\n\n---\n\n## 📚 Documentation Structure\n\n### 🚀 Getting Started\n- **[FRONTEND_SETUP.md](./frontend/FRONTEND_SETUP.md)** - Backend Setup\n```bash\ncd backend\nnpm install\n\n# Create .env file\ncp .env.example .env\n# Edit .env with your database and Clerk keys\n\n# Run migrations\nnpx prisma migrate dev\n\n# Start server\nnpm run dev\n# Backend runs on http://localhost:5000\n```\n\n#### 2. Frontend Setup\n```bash\ncd frontend\nnpm install\n\n# Create .env file\necho 'VITE_CLERK_PUBLISHABLE_KEY=pk_test_your_key_here' > .env\necho 'VITE_API_BASE_URL=http://localhost:5000/api/v1' >> .env\n\n# Start dev server\nnpm run dev\n# Frontend runs on http://localhost:5173\n```\n\n### Using Docker Compose (Recommended)\n```bash\ndocker-compose up\n# Backend: http://localhost:5000\n# Frontend: http://localhost:5173\n# Database: postgres://localhost:5432\n```\n\n---\n\n## ✨ Features\n\n### ✅ Implemented\n- [x] User authentication with Clerk\n- [x] Dashboard with expense overview\n- /api/v1/users/me           Get current user profile\n```\n\n### Invoices (Expenses)\n```\nGET    /api/v1/invoices           List all invoices\nGET    /api/v1/invoices/:id       Get single invoice\nPOST   /api/v1/invoices           Create new invoice\nPUT    /api/v1/invoices/:id       Update invoice\nDELETE /api/v1/invoices/:id       Delete invoice\nGET    /api/v1/invoices/stats     Get expense statistics\n```\n\n### Gmail\n```\nGET    /api/v1/gmail/authorize          Initiate Gmail OAuth\nGET    /api/v1/gmail/oauth/callback     Handle OAuth callback\nGET    /api/v1/gmail/connection         Get Gmail connection status\nPOST   /api/v1/gmail/disconnect         Disconnect Gmail\nPOST   /api/v1/gmail/sync               Sync Gmail emails\n```\n\n### Email\n```\nGET    /api/v1/email/messages           Get email messages\nGET    /api/v1/email/messages/unread    Get unread messages\nPUT    /api/v1/email/messages/:id/read  Mark message as read\nPOST   /api/v1/email/messages/:id/process Process email\n```\n\nSee [INTEGRATION_GUIDE.md](./INTEGRATION_GUIDE.md) for complete endpoint documentation.\n\n---\n\n## 🛠️ Development Commands\n\n### Error\n**Problem**: Frontend can't connect to backend\n\n**Solutions**:\n1. Check backend is running: `http://localhost:5000/health`\n2. Check `.env` file in frontend has correct `VITE_API_BASE_URL`\n3. Check CORS is enabled in backend\n\n### Clerk Authentication Error\n**Problem**: Sign in/sign up not working\n\n**Solutions**:\n1. Verify `VITE_CLERK_PUBLISHABLE_KEY` in frontend `.env`\n2. Verify `CLERK_SECRET_KEY` in backend `.env`\n3. Check Clerk keys are correct for your app\n\n### Database Connection Error\n**Problem**: Backend can't connect to database\n\n**Solutions**:\n1. Check `DATABASE_URL` in backend `.env`\n2. Verify PostgreSQL is running\n3. Run migrations: `npx prisma migrate dev`\n\n### Type Errors\n**Problem**: TypeScript compilation errors\n\n**Solutions**:\n1. Check `src/types/index.ts` for correct interfaces\n2. Verify API response matches type definition\n3. Run `npm run type-check` for detailed errors\n\nSee [DEVELOPER_QUICK_REFERENCE.md](./DEVELOPER_QUICK_REFERENCE.md) for more troubleshooting tips.\n\n---\n\n## 📖 Documentation\n\nComplete documentation available in:\n\n1. **[FRONTEND_SETUP.md](./frontend/FRONTEND_SETUP.md)** - Frontend architecture and setup\n2. **[INTEGRATION_GUIDE.md](./INTEGRATION_GUIDE.md)** - API integration details\n3. **[DEVELOPER_QUICK_REFERENCE.md](./DEVELOPER_QUICK_REFERENCE.md)** - Quick reference for common tasks\n4. **[FILE_INDEX_AND_NAVIGATION.md](./FILE_INDEX_AND_NAVIGATION.md)** - Complete code navigation\n5. **[IMPLEMENTATION_CHECKLIST.md](./IMPLEMENTATION_CHECKLIST.md)** - Status and testing checklist\n6. **[FRONTEND_IMPLEMENTATION_SUMMARY.md](./FRONTEND_IMPLEMENTATION_SUMMARY.md)** - Executive summary\n\n---\n\n## 🎓 Learning Resources\n\n### Frontend\n- [React Documentation](https://react.dev)\n- [React Router Guide](https://reactrouter.com)\n- [React Query Tutorial](https://tanstack.com/query/latest)\n- [TypeScript Handbook](https://www.typescriptlang.org/docs/)\n- [Vite Guide](https://vitejs.dev/guide/)\n\n### Backend\n- [Express.js Guide](https://expressjs.com/)\n- [Prisma Documentation](https://www.prisma.io/docs/)\n- [Clerk Documentation](https://clerk.com/docs)\n- [PostgreSQL Documentation](https://www.postgresql.org/docs/)\n\n---\n\n## 🤝 Contributing\n\n1.
